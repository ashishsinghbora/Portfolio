An interactive, high-performance web terminal operating system and engineering portfolio inspired by `zui.ooo`, engineered by **Ashish Singh Bora** from **Pantnagar, Uttarakhand, India**.

---

## 🌟 Key Features

- **TTY0 Terminal Shell**: Custom command parsing engine with tab auto-completion, command history traversal (`↑` / `↓`), and sanitized arguments.
- **Dual-Mode Experience**: Toggle seamlessly between pure **TTY0 Fullscreen CLI** and **Hybrid Desktop GUI**.
- **Interactive Filesystem (`/projects/`)**: Live directory index rendering case study modals, performance benchmark telemetry, and ASCII architecture diagrams.
- **Synthesized Web Audio FX**: Zero-dependency Web Audio API synthesizer for tactile keystrokes, modal transitions, and command chimes.
- **Live Theme Palette Swapping**: Instant switching between `cyber`, `matrix`, `dracula`, and `nord` with persistent `localStorage` synchronization.
- **Monochrome Visual Archive**: Interactive photography viewer with real-time EXIF extraction (Aperture, Shutter, ISO, Focal Length).
- **Security-First Architecture**: Input sanitization, path traversal mitigation, strict CSP, HSTS, and 26 automated unit/E2E tests.

## 🚀 Interactive Commands

| Command | Description |
|---|---|
| `help` | Display manual with command usage and shortcuts |
| `whoami` | Print identity credentials, node origin, location, and bio |
| `ls -la /projects/` | Render interactive filesystem table with clickable project inspectors |
| `cat <filename>` | Read file contents or render project specifications directly |
| `open <filename>` | Launch deep case study modal with architecture charts and metrics |
| `skills` | Interactive technical capability matrix across 5 core engineering domains |
| `fetch` / `neofetch` | System telemetry, kernel info, uptime, memory bar, and palette preview |
| `theme <name>` | Live swap theme (`cyber` \| `matrix` \| `dracula` \| `nord`) |
| `contact` | Interactive RFC-822 transmission packet dispatcher and mail endpoint |
| `matrix` | Toggle 60 FPS digital rain background canvas overlay |
| `audio` | Toggle Web Audio API synthesized tactile sound FX |
| `gui` / `mode` | Switch between fullscreen TTY0 terminal and hybrid windowed OS |
| `sudo` | Secret privilege check easter egg |
| `reboot` | Re-run animated hardware memory checks and boot sequence |

## 🛠️ Tech Stack & Architecture

- **Core**: Next.js 16 (App Router), TypeScript (Strict)
- **Styling**: Tailwind CSS + CSS Variables for dynamic live palette swapping
- **Animations**: Framer Motion (staggered boot logs, spring modals)
- **Icons**: Lucide React + Custom SVG precision icons
- **Audio**: Web Audio API Synthesizer (Zero asset overhead)
- **Testing**: Vitest, React Testing Library, JSDOM, Playwright
